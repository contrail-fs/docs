### Throttle Reverse

A reverser is only installed on Engine No.2. There are multiple ways of activating the reverser, most of these can be achieved by using virtual buttons which most hardware throttles provide. A normal button on your quadrant can be used as well.

| Description | Name |
| --- | --- |
| Decrease Thrust below Idle Power<br />(enable "Input Repetition") | DECREASE THROTTLE |
| Switch throttle mode to reverse thrust.<br />Advance throttle forward to control the reverser axis.<br />(enable "Input Repetition") | HOLD THROTTLE REVERSE THRUST |
| Same as hold throttle reverse, but button needs to be toggled<br />to switch between modes. No input repetition required. | TOGGLE THROTTLE REVERSE THRUST |
