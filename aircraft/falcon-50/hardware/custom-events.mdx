Our aircraft uses complex custom system logic. If you want to map your hardware properly, follow this guide.

## Ready to use profiles

We provide ready-made [MobiFlight](https://www.mobiflight.com/) projects that already contain every custom event, so you only need to assign your own controllers and devices.

### MobiFlight

<Steps>
  <Step title="Install MobiFlight Connector 11+">
    Download and install [MobiFlight Connector](https://www.mobiflight.com/) version **11 or newer**.
  </Step>
  <Step title="Open a profile">
    In MobiFlight, go to **File → Open…** and select one of the profiles above:

    - `_All.mfproj` — a single tab with all events.
    - `_Panels.mfproj` — tabs grouped by cockpit area.
  </Step>
  <Step title="Assign your hardware">
    For each config, assign a **Controller** and **Device**, then set it to **Active**.
  </Step>
  <Step title="Save the project">
    Save the project so your assignments are kept for next time.
  </Step>
</Steps>

## Direct: simvar bindings

Controls wired **directly** to an MSFS simulation variable (no custom B-event). Map hardware by **setting the simvar**.

| SimVar | Cockpit control | Notes |
| --- | --- | --- |
| `A:ADF SOUND:1, Bool` | ADF1 ident monitor | Toggled via `K:RADIO_ADF_IDENT_SET`. |
| `A:ADF SOUND:2, Bool` | ADF2 ident monitor | Toggled via `K:RADIO_ADF2_IDENT_SET`. |
| `A:BUS CONNECTION ON:20, Bool` | Battery 1 master | OVHD battery switch. Hardware: set simvar to `1` (on) or `0` (off). MobiFlight example: `1 (>A:BUS CONNECTION ON:20, Bool)` |
| `A:BUS CONNECTION ON:21, Bool` | Battery 2 master | OVHD battery switch. Example: `1 (>A:BUS CONNECTION ON:21, Bool)` |
| `A:BUS CONNECTION ON:5, Bool` | Bus D tie | OVHD Bus D knob. Example: `1 (>A:BUS CONNECTION ON:5, Bool)` |
| `A:BUS CONNECTION ON:7, Bool` | Bus C tie | OVHD Bus C knob. Example: `1 (>A:BUS CONNECTION ON:7, Bool)` |
| `A:COM RECEIVE:1, Bool` | COM1 receive active | Toggled via `K:COM1_RECEIVE_SELECT`. |
| `A:COM RECEIVE:2, Bool` | COM2 receive active | Toggled via `K:COM2_RECEIVE_SELECT`. |
| `A:COM RECEIVE:3, Bool` | COM3 receive active | Toggled via `K:COM3_RECEIVE_SELECT`. |
| `A:COM TRANSMIT:1, Bool` | VHF1 TX selected | Set via `K:PILOT_TRANSMITTER_SET` with value `0`. |
| `A:COM TRANSMIT:2, Bool` | VHF2 TX selected | Set via `K:PILOT_TRANSMITTER_SET` with value `1`. |
| `A:COM TRANSMIT:3, Bool` | HF TX selected | Set via `K:PILOT_TRANSMITTER_SET` with value `2`. |
| `A:DME SOUND:1, Bool` | DME1 ident monitor | Toggled via `K:RADIO_DME1_IDENT_SET`. |
| `A:DME SOUND:2, Bool` | DME2 ident monitor | Toggled via `K:RADIO_DME2_IDENT_SET`. |
| `A:MARKER SOUND:1, Bool` | Marker ident monitor state | Written via `K:MARKER_SOUND_TOGGLE` from audio panel. |
| `A:NAV SOUND:1, Bool` | NAV1 ident monitor | Toggled via `K:RADIO_VOR1_IDENT_SET`. |
| `A:NAV SOUND:2, Bool` | NAV2 ident monitor | Toggled via `K:RADIO_VOR2_IDENT_SET`. |
