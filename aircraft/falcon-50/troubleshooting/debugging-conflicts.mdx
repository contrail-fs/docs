---
title: "Debugging Conflicts"
description: "Quickly isolate whether unexpected Falcon 50 behavior is caused by another add-on, your hardware, or a corrupted cache."
---

Unexpected behavior in the Falcon 50 is usually caused by **another add-on**, a **hardware / keybinding conflict**, or a **corrupted cache** — not the aircraft itself. Common symptoms: the aircraft is missing from the menu, displays are blank or frozen, controls or the autopilot act up, or the aircraft crashes on load.

Work through the steps below in order and stop as soon as the issue is fixed.

## 1. Clear the caches

<Steps>
  <Step title="WASM cache">
    The Contrail App clears this automatically, but clearing it manually doesn't hurt. **If you bought the aircraft from a third-party store, this step is mandatory.**

    Delete everything inside the folder for your version and store (leave any `Work` subfolder alone):

    **MSFS 2024**
    - **Microsoft Store:** `%LocalAppData%\Packages\Microsoft.Limitless_8wekyb3d8bbwe\LocalState\WASM\ctl-aircraft-fa50`
    - **Steam:** `%AppData%\Microsoft Flight Simulator 2024\WASM\ctl-aircraft-fa50`

    **MSFS 2020**
    - **Microsoft Store:** `%LocalAppData%\Packages\Microsoft.FlightSimulator_8wekyb3d8bbwe\LocalState\packages\ctl-aircraft-fa50\work`
    - **Steam:** `%AppData%\Microsoft Flight Simulator\Packages\ctl-aircraft-fa50\work`
  </Step>
  <Step title="JavaScript cache">
    Start MSFS, load a flight with a **default aircraft**, then close the sim. This clears the cached JavaScript for our aircraft.
  </Step>
</Steps>

## 2. Rule out other add-ons

Run the Falcon 50 completely on its own for one session:

- **Community folder:** rename it (e.g. `Community` → `Community_OFF`), create a fresh empty `Community`, and move **only** the `ctl-aircraft-fa50` folder into it. Repeat for each sim if you run both MSFS 2020 and 2024.
- **Marketplace content:** disable it from the in-sim **Content Manager** (it doesn't live in the Community folder).
- **External tools:** fully quit MobiFlight, SPAD.neXt, ActiveSky, FSRealistic, and similar.

Then start a flight with the Falcon 50:

- **Issue gone?** An add-on caused it. Re-enable add-ons one at a time (restarting the sim each round) until it returns — the last one is the culprit.
- **Issue remains?** Move on to hardware.

<Tip>
  A free add-on linker like [MSFS Addons Linker](https://de.flightsim.to/file/1572/msfs-addons-linker) lets you toggle packages without moving folders — and run just one aircraft per session, which prevents most conflicts.
</Tip>

## 3. Rule out hardware

Especially for flight-control, trim, or autopilot issues:

- Unplug any hardware not essential for flying, or switch to a different controller.
- In the MSFS **Controls** settings, remove **duplicate or conflicting bindings** (the same axis/button assigned twice).

Some third-party add-ons overwrite standard MSFS functions or displays and break our aircraft. Run **one aircraft add-on per session** to avoid this.
