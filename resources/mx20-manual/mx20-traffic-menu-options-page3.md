## <span id="page-62-0"></span>Traffic Menu Option Page 3

The third menu option page of the Traffic function lets you select options for the choices of Display mode, Flight ID Editing, and Labeling. The last option selection takes you back to the first page of options.

### Display Mode

The display mode lets you select either a graphic or text version of traffic information.
