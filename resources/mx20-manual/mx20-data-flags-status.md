## <span id="page-18-0"></span>Data Flags

Data flags appear on the left side of the display to notify you when there is a loss of reported information. The data usually displayed, such as lightning or nearby terrain, may still exist, but may not be displayed for technical reasons. For instance, when the amber TRAF data flag appears it means that the MX20 is not receiving Traffic information from the sensor. So, traffic may exist in your vicinity, but will not be displayed on the MX20. All flags are amber unless otherwise indicated.

| Data Flag | Description                                                                                                                                                                            |
|-----------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|           | No valid position information is available from the<br>source. Do not expect a valid position representation<br>on the maps. The Ownship symbol will have an "X"<br>through it.        |
|           | No valid route (flight plan) is available from the exter<br>nal navigation source. Route (flight plan) information<br>will not be shown on the maps.                                   |
|           | No valid altitude information is available from the<br>external source. Altitude related functions will not<br>operate, such as terrain awareness.                                     |
|           | No traffic information is received from the optional<br>traffic sensor. Traffic will not be displayed. Your posi<br>tion information may not be broadcast in ADS-B<br>capable systems. |
|           | The GPS receiver in the GDL 90 UAT is not reporting<br>a valid position. ADS-B broadcast will not include a<br>position report.                                                        |
|           | No valid lightning detection information is being<br>received from the optional Stormscope sensor. Strike<br>and cell information will not be displayed.                               |
