## Flight ID Editing

The Enter Flight ID option allows you to edit your broadcasted Flight ID when the editing function is enabled. The Function "smart" keys at the bottom of the screen change to arrow keys. Use the UP/DOWN arrow keys to change the characters. Use the LEFT/RIGHT arrow keys to move between characters. Press the MENU/ENTER key to save the displayed Flight ID. The Flight ID is only sent when the Flight ID broadcast option is enabled. Note that the GDL 90 UAT does not allow the space or period characters. The MX20 must be configured as the UAT's control panel to make this function available.

### Label

The LABEL menu key toggles the state of the labels adjacent to the target symbols. Turning labels off will remove the Flight ID and flight vector.
