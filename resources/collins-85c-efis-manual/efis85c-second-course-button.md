# 2ND CRS (Second Course) Button

Sequentially push the 2ND CRS button to allow information from a second navigation sensor to be displayed on the EHSI.

The second course arrow is displayed in cyan as a solid single bar course arrow. The possible selections depend upon interconnect wiring (both strapping and installer supplied switching). The applicable sensor is annunciated in cyan above the active selected course arrow sensor annunciator.

At power on, no second course arrow is displayed. Sequentially pushing the 2ND CRS button selects VOR1/LOC1, VOR2/LOC2, LRN1 (which may be an INS, VLF, LRN, LNV, GPS or FMS), LRN2 and off for the pilot's DCP; and VOR2/LOC2, VOR1/LOC1, LRN2, LRN1 and off for the copilot's DCP. MLS and "ADF can also be on the second course arrow. Holding the 2ND CRS button for longer than approximately 1/2 second causes the second course selection to cycle directly to the off state.
