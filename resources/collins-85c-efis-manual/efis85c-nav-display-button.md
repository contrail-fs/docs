# NAV (Navigation) Button

Push and release this button to turn on or off the navigation (NAV) display mode.

The NAV and RDR display modes can be turned on at the same time. When any other display mode is selected (RMT, PGE, or EMG) the display goes directly to that mode. Also, from the RMT, PGE or EMG display modes, pushing the NAV button changes the display directly to the NAV mode.
