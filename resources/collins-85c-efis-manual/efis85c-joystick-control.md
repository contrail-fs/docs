# Joystick

The "joystick" is a multiple position switch that is used in NAV, RMT, PGE and EMG mode operations.

In the NAV menu mode, move the joystick as indicated to select the number of NAVAIDS and airports to show on the display in the NAV mode.

In NAV mode, move the joystick as necessary to position a waypoint on the MFD display that can be transferred to compatible LNAV systems.

In RMT mode, move the joystick as necessary to slew through pages or chapters of data of a compatible remote system.
