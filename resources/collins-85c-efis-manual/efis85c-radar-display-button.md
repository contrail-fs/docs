# RDR (Radar) Button

Push and release this button to turn on or off the radar (RDR) display mode.

The RDR and NAV display modes can be turned on at the same time. When any other display mode is selected (RMT, PGE or EMG) the display goes directly to that mode. Also, from the RMT, PGE or EMG display modes, pushing the RDR button changes the display directly to the RDR mode.
