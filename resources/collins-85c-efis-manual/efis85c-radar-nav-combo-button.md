# Radar and Navigation) Button

Push the  $\frac{RDR}{NAV}$  button to turn on and off the radar (RDR) and navigation (NAV) display modes.

Each push of the  $\frac{RDR}{NAV}$  button cycles the MFD through a sequence of radar and navigation display modes. The first push of the  $\frac{RDR}{NAV}$  button turns on the RDR display mode; the second push turns on the NAV mode with the RDR mode; the third push turns off the RDR mode and leaves the NAV mode on; and a fourth push of the button turns off the NAV mode and turns on the RDR mode. Push any other display mode button, at any time, to exit the currently selected RDR and/or NAV display mode(s) and change the MFD directly to that mode. Selection of any other mode causes the MFD to store, in memory, the currently selected NAV and/or RDR display mode(s) and display options. From any other display mode, push the  $\frac{RDR}{NAV}$  button at any time to return to the last selected RDR and/or NAV display mode(s).

#### WARNING

Changing the MFD display from the RDR display mode or turning off the RDR display mode does not turn off or change the operating mode of the radar receiver/transmitter. The WXP controls the weather radar receiver/transmitter operating modes. For installations with a WXP-850() the radar transmits when the MODE switch is set to the TGT, MAP, WX, WX+T or TURB modes.

#### NOTE

Any time that the RDR mode shows on the display, with or without the NAV mode, the WXP controls the display range.
