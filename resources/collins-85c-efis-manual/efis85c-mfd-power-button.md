# PWR (Power) Button

Push this button to turn the MFD on or off.

The PWR button is a latching push on/push off type switch. The MFD is turned on when the button is pushed in and off when it is in the out position.

The MFD stores the selected display mode(s) and options in memory when power is turned off. When power is turned on, the MFD shows the stored display mode(s) and options.

#### WARNING

Turning off power on the MFD does not turn off power to weather radar systems and does not put radar systems in a non-transmitting mode. The WXP controls the radar receiver-transmitter operating modes. For installations with a WXP-850() the radar transmits when the MODE switch is set to the TGT, MAP, WX, WX+T or TURB modes.
