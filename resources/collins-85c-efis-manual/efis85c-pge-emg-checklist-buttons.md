# PGE (Page) and EMG (Emergency) Buttons

Push and release these buttons as necessary to show page or emergency data information.

When a PGE or EMG button is pushed the MFD goes directly to the line-key menus or display pages for the data that is stored in the MFD. To exit PGE and RMT display modes, push any other display mode button. The MFD changes directly to the selected mode.

Up to 100 pages of data are available for checklists and emergency use. These buttons are also used to load page and emergency data through the data jack on the MFD.
