# SEC (Sector Scan) Button

Push the SEC button to reduce the normal 120 degree scan to a 60 degree scan (30 degrees either side of center).

The SEC button is a push on/push off momentary button. Each push of the button toggles the sector scan mode on or off.

Reducing the sector scan increases the radar display update rate. When dual WXPs are installed, either WXP can turn on or off the SEC scan mode. When sector scan is turned on, all EFIS displays in the radar display mode show the reduced sector scan display. The SEC display mode stays on until turned off by a push of the SEC button. The SEC display mode is identified by the reduced size of the range arcs.

### TILT Control

Turn the TILT knob to manually set the tilt angle of the radar antenna.

Tilt can be set at each quarter of a degree to a maximum of ±15 degrees. However, tilt settings are annunciated on EFIS only to one decimal point (i.e., +10.5, -5.2, etc.). The second digit after the decimal point (either a 5 or a 0) is not shown.
