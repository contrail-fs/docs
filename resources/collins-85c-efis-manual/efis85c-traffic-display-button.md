# TFC (Traffic) Button

Push the TFC button to turn on the TCAS traffic display mode and/or the TCAS line-key menu along the right side of the display.

When the MFD is in any display mode other than the TFC display mode, pushing the TFC button changes the MFD directly to the TFC display mode. Pushing the TFC button or any line key when the MFD is in the TFC display mode, turns on the TFC display line-key menu. The TFC fine-key menu turns off after approximately 5 seconds of no selection activity.

To exit the TFC display mode, push any other display mode button to change to that mode.
