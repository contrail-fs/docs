# RMT (Remote) Button

Push and release this button to show the remote data source line-key menu for the line select keys.

When the RMT button is pushed, the MFD goes directly to the remote line key menu display mode. To exit the RMT display mode, push any other display mode button. The MFD changes directly to the selected mode.
